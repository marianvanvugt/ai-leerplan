1
Begrijp hoe AI & LLMs werken
Week 1–3 · conceptueel fundament
▾

Voordat je AI gaat inzetten, wil je snappen wat er onder de motorkap zit — niet als wiskundige, maar als iemand die wil begrijpen waarom een LLM soms hallucineert, wat een context window is, en waarom prompt-formulering zo cruciaal is.

Cursus: Elements of AI Univ. Helsinki · gratis · NL
De beste niet-technische AI-introductie die er is, nu ook beschikbaar in het Nederlands. Behandelt wat AI is, machine learning, neurale netwerken en ethiek. Op eigen tempo, geen wiskundige achtergrond nodig. Meer dan 2 miljoen studenten wereldwijd.
→ elementsofai.com (NL) → Building AI (vervolg)
Cursus: AI for Everyone — Andrew Ng Coursera · gratis
Niet-technische cursus (±6 uur) die uitlegt wat AI kan en niet kan, hoe je AI-projecten aanpakt, en wat de zakelijke impact is. Gratis te auditen. Andrew Ng is de bekendste AI-docent ter wereld en houdt de toon toegankelijk.
→ Coursera (gratis auditen)
Video: But what is a neural network? — 3Blue1Brown
De beste visuele uitleg van neurale netwerken die bestaat. Geen enkele technische achtergrond nodig — alles wordt met animaties uitgelegd. Bekijk de eerste 3 video's van de serie voor een solide visueel fundament.
▶ YouTube serie
💡 Tip: Gebruik Claude als studie-assistent terwijl je deze cursussen doorloopt. Stel vragen als: "Wat is het verschil tussen een LLM en een traditioneel ML-model?" of "Leg mij hallucination uit alsof ik data analist ben." Zo verdiep je begrip actief.
2
Prompt engineering als vaardigheid
Week 3–5 · directe impact op je werk
▾

Goede prompts schrijven is een echte vaardigheid — zeker als data analist die wil werken met gestructureerde output. Leer hoe je AI instrueert zodat de output direct bruikbaar is in jouw werkproces.

Lees: Anthropic Prompt Engineering Guide Anthropic · 2025
De officiële documentatie van Anthropic over effectief prompts bouwen voor Claude. Behandelt chain-of-thought redeneren, XML-structuur, few-shot voorbeelden, en output-formatting. Actueel en praktisch.
→ docs.anthropic.com → Claude blog: Best Practices
Interactief: Anthropic Prompt Engineering Tutorial Anthropic · GitHub
Hands-on tutorial rechtstreeks van Anthropic — doorloop de oefeningen in volgorde. Je leert prompts iteratief verbeteren met directe feedback. Beschikbaar als Jupyter Notebook (aanbevolen als je Python al hebt) of als Google Sheets versie.
→ GitHub Tutorial
Opdracht: Schrijf een prompt die jouw SQL-werk analyseert
Pak een echte SQL-query van je werk. Schrijf een prompt die Claude vraagt om: (1) de query stap voor stap uit te leggen, (2) verbeteringen voor te stellen, en (3) de output te formatteren als een gestructureerd rapport. Itereer de prompt tot het resultaat bruikbaar is.
→ Claude.ai
Opdracht: Bouw een persoonlijke prompt-bibliotheek
Maak een document waar je jouw beste prompts opslaat per gebruik: SQL-analyse, data-samenvatting, rapportage, e-mail schrijven. Begin klein. Na een maand heb je een waardevolle persoonlijke gereedschapskist die groeit met je ervaring.
→ Notion (gratis)
💡 Tip: Anthropic biedt ook een gestructureerde prompting cursus aan via anthropic.skilljar.com — vermeld in de officiële docs als de plek om prompting serieus te oefenen met toetsvragen en feedback.
3
Python basics voor AI-gebruik
Week 5–9 · de toegangspoort
▾

Je hoeft geen Python-ontwikkelaar te worden. Maar als je een API kunt aanroepen en JSON kunt verwerken, gaan er enorm veel deuren open. Je kent SQL al — de logica van "data ophalen, verwerken, outputten" is vergelijkbaar.

Installeer Python + Jupyter via Anaconda
Anaconda geeft je Python, Jupyter én pandas in één installatie. Jupyter is ideaal voor experimenteren: je draait code stap voor stap en ziet het resultaat direct — net als een interactieve rekenmachine voor data.
→ Anaconda download (gratis)
Cursus: Python for Everybody — University of Michigan Coursera · gratis
De klassieke Python-instap cursus voor beginners. Gratis te auditen. Je hoeft niet de hele specialisatie te doen — de eerste twee modules (variabelen, functies, loops, bestanden) zijn al genoeg om door te gaan naar AI-gebruik.
→ Coursera (gratis)
Opdracht: Roep de Claude API aan vanuit Python Anthropic
Installeer de Anthropic SDK (pip install anthropic), maak een API-sleutel aan op console.anthropic.com, en stuur je eerste bericht via Python. Verwerk het antwoord en druk het af. Dit is het technische fundament van alles wat volgt.
→ Anthropic API docs → API key aanmaken
Mini-project: Laat AI een CSV analyseren
Pak een CSV van je werk (anonimiseer indien nodig). Lees het in met pandas, stuur een samenvatting naar de Claude API, en druk de AI-analyse af in een leesbaar formaat. Je eerste echte AI + data-integratie — direct toepasbaar in je werk.
→ pandas quickstart
💡 Tip: Gebruik Claude om je Python-code te debuggen terwijl je leert. Plak een foutmelding in Claude en vraag: "Leg uit wat er fout gaat en hoe ik dit oplossen kan." Je oefent zo Python én prompting tegelijk.
4
AI Agents begrijpen & bouwen
Week 9–13 · het kernonderwerp
▾

Een AI agent is een LLM die tools kan gebruiken (databases, API's, bestanden) en zelfstandig meerdere stappen kan plannen. Dit is de meest relevante ontwikkeling voor data analisten — een agent die zelf queries schrijft, resultaten beoordeelt en een rapport genereert.

Lees: Building Effective Agents Anthropic · 2024
Het essentiële artikel van Anthropic over hoe je goede AI agents bouwt — welke patronen werken, wanneer je agents inzet versus eenvoudigere oplossingen, en welke valkuilen te vermijden. Rechtstreeks van de makers van Claude, geschreven voor een technisch publiek zonder ML-achtergrond.
→ anthropic.com
Visueel starten: maak kennis met n8n geen code nodig
n8n is een visuele workflow-tool waarmee je AI-agents kunt bouwen zonder te programmeren. Perfect als eerste kennismaking met het concept van "input → beslissing → actie." Probeer de gratis cloud-versie en koppel een LLM aan een simpele automatisering.
→ n8n.io → n8n cursus (gratis)
Cursus: Agentic AI — Andrew Ng DeepLearning.AI · 2025
Korte praktische cursus over het bouwen van agentic AI-systemen: reflection (AI die zijn eigen werk beoordeelt), tool use, planning en multi-agent samenwerking. Gratis. Geeft je echt inzicht in hoe agents werken aan de hand van concrete code-voorbeelden.
→ DeepLearning.AI (gratis)
Lees: Effective Context Engineering for AI Agents Anthropic Engineering · 2025
Anthropic's eigen verdieping op hoe agents optimaal gebruik maken van hun context-window — de volgende stap na prompt engineering. Legt uit waarom "context engineering" de nieuwe vaardigheid is voor iedereen die met agents bouwt.
→ anthropic.com/engineering
Mini-project: Bouw een "data-analist agent"
Maak een Python-script (of n8n-flow) waar je een vraag in gewone taal stelt over een dataset. De agent genereert zelf een SQL-query, voert die uit op een lokale SQLite database, en vat de uitkomst samen in begrijpelijke taal. Dit is een realistisch scenario voor jouw dagelijks werk.
→ Anthropic Tool Use docs → SQLite (lokale database)
💡 Tip: Begin met n8n als je nog weinig Python-ervaring hebt. Zodra je in n8n ziet hoe de stroom input → beslissing → actie → output werkt, is de vertaling naar Python-code veel logischer en kleiner dan het lijkt.
5
RAG & AI op jouw eigen data
Week 13–17 · het verschil maken
▾

RAG (Retrieval-Augmented Generation) is de techniek waarmee je een LLM toegang geeft tot jouw eigen data — documenten, databases, interne rapporten. Als data analist ga je hier zeker mee te maken krijgen. Dit is hoe bedrijven AI écht productief gaan inzetten.

Cursus: AI Agents in LangGraph DeepLearning.AI · 2024
Praktische cursus (±3 uur) over het bouwen van agents met LangGraph — inclusief state management, geheugen over meerdere gesprekken en human-in-the-loop controle. Directe toepassing voor data-analyse workflows. Gratis.
→ DeepLearning.AI (gratis)
Lees: What is RAG? IBM · 2024
Heldere introductie op RAG zonder code. Begrijp de kerngedachte: een LLM weet niet alles, dus we geven hem real-time toegang tot een zoeksysteem op jouw eigen data. Het fundament van bijna elke bedrijfs-AI-toepassing.
→ IBM: What is RAG?
Mini-project: Chatbot op een intern document
Neem een PDF of tekstbestand (bijv. een intern rapport of handleiding van je werk). Bouw met LlamaIndex een eenvoudige chatbot die in gewone taal vragen beantwoordt over dat document. Dit is RAG in zijn eenvoudigste vorm — en meteen bruikbaar.
→ LlamaIndex quickstart
Verdieping: Tableau AI verkennen Tableau · 2024
Tableau heeft steeds meer ingebouwde AI-functies: Tableau Pulse, AI-gegenereerde inzichten en Ask Data. Bekijk wat er nu beschikbaar is en hoe het aansluit op je bestaande Tableau-werk. Zo zie je hoe AI en je huidige toolstack samenkomen.
→ Tableau AI → Ask Data
Blijf bij: Anthropic Engineering Blog Anthropic · actueel
Houd de Anthropic Engineering Blog bij voor de nieuwste ontwikkelingen — van agent-patronen tot praktische implementatiegidsen. Geschreven door de engineers die Claude bouwen. Nieuwe, inhoudelijke artikelen verschijnen regelmatig en zijn goed leesbaar zonder ML-achtergrond.
→ anthropic.com/engineering
💡 Tip: Na fase 5 ben je in staat om op je werk concrete AI-toepassingen voor te stellen en uit te leggen. Denk aan: "We kunnen collega's in gewone taal vragen laten stellen over onze data-rapportages." Dat is een voorstel dat je nu kunt onderbouwen én zelf bouwen.
6
Vibe coding met Claude Code
Week 17–22 · van idee naar werkende app
▾

Vibe coding is het bouwen van werkende applicaties door gewoon in gewone taal te beschrijven wat je wilt — zonder zelf code te schrijven. Claude Code is het gereedschap van Anthropic dat dit mogelijk maakt: het leest je projectmap, schrijft bestanden, voert commando's uit en debugt zelfstandig. Voor een data analist betekent dit: van idee tot werkende tool in een middag, in plaats van weken. De platforms Netlify, Cloudflare en Supabase zijn de infrastructuur waarop je die apps publiceert en draait.

Installeer & verken Claude Code Anthropic · 2025
Claude Code werkt als een CLI-tool in je terminal — het ziet je hele projectmap en werkt autonoom. Installeer het via npm install -g @anthropic-ai/claude-code, open een leeg project en geef je eerste instructie in gewone taal. De officiële docs begeleiden je stap voor stap.
→ Claude Code docs → Claude Code web (geen installatie)
Lees: Vibe Coding Best Practices Guide Anthropic artifact · 2025
Anthropic's eigen gids over hoe je effectief vibe codet met Claude Code: hoe je instructies structureert, wanneer je ingrijpt, en hoe je voorkomt dat Claude "off the rails" gaat. Essentieel voordat je serieus begint.
→ Vibe Coding gids (ClaudeLog)
Mini-project: Bouw een data-dashboard in één sessie
Maak een leeg project-mapje. Open Claude Code. Beschrijf in gewone taal wat je wilt: "Bouw een HTML-pagina die een CSV-bestand inleest en de data weergeeft als grafiek." Laat Claude het volledig uitwerken. Observeer hoe het denkt en bestanden aanmaakt. Grijp in wanneer het de verkeerde kant opgaat.
→ Complete beginner-gids Claude Code
Platform: Netlify — je app online zetten in één klik gratis tier
Netlify is de eenvoudigste manier om een app die Claude Code heeft gebouwd, online te zetten. Koppel je GitHub-repository en elke nieuwe versie die je pusht wordt automatisch gepubliceerd. Gratis tier is ruim genoeg voor persoonlijke projecten en prototypes. Claude Code kent Netlify's configuratie en kan de netlify.toml voor je schrijven.
→ netlify.com (gratis) → Netlify docs
Platform: Cloudflare Pages & Workers — sneller en globaal gratis tier
Cloudflare Pages is een alternatief voor Netlify — met dezelfde eenvoud maar gebouwd op Cloudflare's wereldwijde netwerk (300+ locaties). Cloudflare Workers voegt serverless backend-logica toe. Ideaal als je app ook API-calls doet of data transformeert. Combineer met Supabase voor een volledige gratis stack.
→ Cloudflare Pages → Cloudflare Workers
Platform: Supabase — database + auth voor je app gratis tier · PostgreSQL
Supabase geeft je een volledige PostgreSQL-database, gebruikersauthenticatie, bestandsopslag en realtime updates — allemaal via een eenvoudige API. Als data analist herken je de SQL-laag meteen. Claude Code weet hoe Supabase werkt en kan de koppeling voor je schrijven. Werkt naadloos samen met zowel Netlify als Cloudflare.
→ supabase.com (gratis) → Supabase docs
Eindproject: Bouw en publiceer een volledige data-tool
Combineer alles: gebruik Claude Code om een werkende webapp te bouwen die data opslaat in Supabase, gepubliceerd wordt via Netlify of Cloudflare, en een eenvoudige interface heeft. Denk aan een intern rapportage-dashboard, een formulier dat data opslaat, of een tool die CSV-uploads analyseert. Je hebt de hele stack nu in handen.
→ Cloudflare + Supabase integratie → Netlify + Supabase integratie
💡 Tip: Maak altijd een CLAUDE.md bestand in je projectmap — dit is Claude Code's "geheugen" voor dat project. Schrijf daarin: welk framework je gebruikt, wat de stijlrichtlijnen zijn, en wat Claude niet mag aanpassen. Dit voorkomt de meeste "off the rails" situaties en maakt elke sessie consistenter.
